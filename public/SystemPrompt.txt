INSTRUCCIONES DEL SISTEMA — TUTOR 577a
=====================================================

[ PENDIENTE ]

Este archivo documenta el system prompt del tutor 577a. La app NO
carga este archivo en runtime (el system prompt está inline en
`src/lib/gemini.ts` como constante `SYSTEM_PROMPT`).

Pasos para terminar la ingesta de la materia 577a:

1. Pegá el system prompt real de la materia dentro de la constante
   `SYSTEM_PROMPT` en `src/lib/gemini.ts` (reemplazá el placeholder
   entre los backticks ` `).

2. Cambiá `ASSISTANT_LABEL` (mismo archivo) por el nombre real de
   la materia, p. ej.:
     "Asistente 577a — Neuropsicología (UBA, FADU)"

3. Copiá los PDFs de la materia adentro de esta carpeta `public/`
   y registralos en `PDF_SOURCES` (mismo archivo). Cada entrada es:
     { name: "U1.pdf", path: `${VITE_BASE_URL}U1.pdf` }

4. (Opcional) Si querés que esta copia del prompt viva también
   acá como referencia humana, pegala debajo de este bloque.

Mientras los pasos 1 y 3 no estén hechos, la app funciona pero el
modelo responde sin contexto y `askGemini()` puede arrojar
"La base de conocimiento está vacía…".
